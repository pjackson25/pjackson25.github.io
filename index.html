Professional Self-Assessment

Completing the Bachelor of Science in Computer Science program has allowed me to develop from a student learning individual programming concepts into a computer science professional who can approach problems through software engineering, data management, algorithmic thinking, security, and effective communication.

Throughout the program, I have learned that developing a successful computing solution involves more than writing functional code. It requires understanding the needs of users and stakeholders, selecting appropriate technologies, evaluating design decisions, protecting data and resources, testing solutions, and communicating technical information in ways that support organizational goals.

My coursework has also helped shape my professional goals and identify the areas of computer science that interest me most. My professional experience in laboratory environments and regulatory and compliance work has shown me the importance of accurate, reliable, and accessible information. As I progressed through the Computer Science program, I became particularly interested in how data is collected, validated, stored, retrieved, protected, and ultimately used to support decision-making.

Collaboration and Communication

One of the most important skills I developed throughout the program was the ability to consider computing problems from perspectives other than my own. Computer science professionals rarely develop solutions in isolation. They must communicate with developers, managers, clients, users, and other stakeholders who may have different levels of technical knowledge.

I learned that effective technical communication must be adapted to the audience. A developer may need detailed information about program logic, database structures, or API behavior, while a manager or business stakeholder may be more interested in what the solution accomplishes and how it supports organizational objectives. Projects involving documentation, presentations, diagrams, dashboards, and written analyses strengthened my ability to communicate technical information in multiple formats.

Software Engineering and Databases

Software engineering coursework strengthened my ability to approach application development systematically rather than treating programming as simply writing code that produces an expected result. I gained experience with application architecture, object-oriented concepts, full-stack development, APIs, testing, debugging, validation, and maintainability.

Database development became an especially important part of my academic growth. Through projects involving SQL, MongoDB, Mongoose, CRUD operations, and application-to-database integration, I developed a stronger understanding of how information should be structured and managed. These experiences strengthened my interest in data analytics, database development, and data engineering.

Data Structures and Algorithms

My coursework in algorithms and data structures strengthened my ability to think about not only whether a solution works, but also how efficiently and effectively it solves a problem. I learned to evaluate different approaches, consider computational trade-offs, and select structures and algorithms appropriate to the requirements of an application.

Security

Another important area of growth throughout the Computer Science program has been developing a security mindset. I learned that security should not be treated as an additional feature considered only after an application has been developed. Instead, security considerations should influence decisions throughout the software development process.

My coursework provided experience with authentication, authorization, input validation, data protection, secure application design, and identifying potential vulnerabilities. These experiences taught me to consider the confidentiality, integrity, and availability of information when designing computing solutions.

ePortfolio and Professional Growth

Developing my CS 499 ePortfolio gave me an opportunity to bring these areas of computer science together and evaluate how my skills have developed throughout the program. For my capstone, I selected the Travlr Getaways full-stack application originally developed in CS 465 because its architecture allowed me to demonstrate growth across software design and engineering, algorithms and data structures, and databases within one integrated application.

The artifacts presented in this ePortfolio demonstrate my progression from developing an application to evaluating and improving an existing computing solution. Together with my broader coursework, these experiences demonstrate my preparation to continue developing as a computer science professional and contribute computing solutions that are reliable, efficient, secure, and valuable to organizations and their users.

Software Design and Engineering

The first enhancement focuses on improving the architecture, reliability, security, validation, error handling, and maintainability of the Travlr Getaways application.

Enhancement One: Software Design and Engineering

For this enhancement, I improved the Travlr Getaways full-stack web application originally developed in CS 465. The enhancement focused on strengthening the application's functionality, maintainability, security, and overall software design.

I expanded the REST API to support dynamic searching, filtering, and sorting of trip information. I also improved input validation, worked with JWT-based authentication and environment configuration, and tested the application to ensure that both existing and enhanced functionality continued to operate correctly.

Through this enhancement, I demonstrated my ability to analyze an existing software system, design and implement improvements, troubleshoot integration issues, consider security requirements, and test a working full-stack application.

Technologies: JavaScript, Node.js, Express, MongoDB, Mongoose, REST API, Passport, and JSON Web Tokens (JWT)

Algorithms and Data Structures

The second enhancement expands the application's trip-processing capabilities through search, filtering, sorting, pagination, and combined query operations. These improvements demonstrate algorithmic problem-solving and consideration of efficiency, usability, and scalability.

Enhancement Two: Algorithms and Data Structures

For this enhancement, I expanded the Travlr Getaways application by implementing more advanced methods for searching, filtering, sorting, and paginating trip data. These improvements allow users to retrieve relevant trip information more efficiently while demonstrating the application of algorithms and data structures to a full-stack application.

The enhanced REST API supports keyword searches across trip names, resorts, and descriptions, as well as resort filtering and sorting. Pagination was also implemented to divide larger result sets into manageable pages. These operations can be combined, allowing the application to process multiple query parameters within a single request.

I tested the enhanced functionality using API requests to verify search, filtering, sorting, pagination, and combined query operations. Through this enhancement, I demonstrated algorithmic problem-solving, consideration of efficiency and scalability, and the ability to integrate data-processing functionality into an existing software system.

Key Features: Search, filtering, sorting, pagination, combined query processing, REST API integration, and input validation.

Databases

The third enhancement strengthens the MongoDB and Mongoose implementation through schema validation, indexing, query optimization, and improved data integrity. Query execution was evaluated to verify that database indexes were being used appropriately.

Enhancement Three: Databases

For this enhancement, I strengthened the database layer of the Travlr Getaways application by improving MongoDB and Mongoose validation, indexing, query performance, and data integrity. These improvements help ensure that trip information is stored consistently and can be retrieved efficiently.

I enhanced the Mongoose trip schema by enforcing required fields and strengthening the trip code with uniqueness and indexing requirements. I also added and verified indexes for commonly accessed fields, including trip code, name, and resort.

I tested the database enhancements directly in MongoDB. Duplicate trip codes were rejected with a duplicate-key error, required-field validation prevented incomplete records from being accepted, and MongoDB execution plans demonstrated that the added indexes could be used during queries.

Through this enhancement, I demonstrated database design, data validation, indexing, query optimization, testing, and data-integrity practices while maintaining integration with the existing full-stack application.

Key Features: Schema validation, unique trip codes, MongoDB indexing, indexed query execution, data-integrity enforcement, and database testing.
